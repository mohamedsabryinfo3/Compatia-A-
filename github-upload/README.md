## التشغيل

افتح `index.html` بنقرة مزدوجة في أي متصفح. لا يحتاج خادماً ولا إنترنت.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (Public)
2. ارفع محتوى هذا المجلد (`index.html` + `README.md`) إلى الفرع `main`
3. اذهب إلى **Settings → Pages**
4. تحت **Source** اختر الفرع `main` والمجلد `/ (root)`
5. اضغط **Save** — يظهر الرابط بعد ثوانٍ:
   `https://USERNAME.github.io/REPO-NAME/`
